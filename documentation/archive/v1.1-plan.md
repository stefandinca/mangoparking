# Mango Parking — v1.1 Plan

Source: `documentation/Notes Mango 3.docx` (client feedback, 2026-05-15).

## Locked decisions

- **Google Reviews URL**: `https://maps.app.goo.gl/ZeDmitAccYJ6K9nQ6`
- **Cashbook handover**: simple — record "handed over to {name} at {time}", no approval workflow.
- **Cancellation**: refund logic (not just a status flip). Online-paid → Netopia refund attempt; cash/card-paid → marked for manual refund.

---

## Round A — Quick wins

- Remove the duplicate WhatsApp button visible on mobile.
- Pay-at-pickup button copy: swap "Plătește cu Netopia" → "Confirmă rezervarea" (longterm) / "Confirmă comanda" (credits) when pay-at-pickup is selected.
- Rename "Istoric credite" → "Istoric rezervări" in i18n + nav + page title.
- Add credits explainer text on home: `parchezi zilnic · parcare navetiști · 1 credit = 1 zi de parcare (L–V 06:00–20:00)`.
- Add Google Reviews link to the home reviews section → `https://maps.app.goo.gl/ZeDmitAccYJ6K9nQ6`.

## Round B — Billing & pre-fill

- PF billing simplification:
  - Drop the required idType radio + idNumber field.
  - New required: `firstName`, `lastName`, `locality` (new), `address`.
  - CNP becomes a single optional field.
  - Returned schema: `{ type: 'PF', firstName, lastName, locality, address, cnp? }`.
- Auto pre-fill from `users/{uid}.billing` in `BookingLongTerm.js` and `BookingCredits.js` on form mount.

## Round C — History + cancellation with refund

- Verify history shows all reservation types (longterm + credit txns).
- Cancel button per upcoming booking.
- Refund logic:
  - Online-paid → callable `cancelBookingWithRefund` issues Netopia refund (or queues manual refund if API not available), flips booking to `cancelled`, releases reserved spot.
  - Cash/card-paid → `paymentStatus: 'refund-pending'`, audit-logged, admin sees it in cashbook for manual handling.
  - Unpaid pay-at-pickup → simple cancel, release spot, no money movement.

## Round D — Step-through date picker

- 4-step wizard inside the existing date field: dropoff date → dropoff time → pickup date → pickup time.
- Each step auto-advances on selection.
- Built on flatpickr (already themed in v1).

## Round E — Admin "Încasează acum" + simple cashbook

- Expand `adminMarkOrderPaid` callable to accept `payerDetails: { firstName, lastName, locality, address }` and patch the booking's billing field.
- "Mark paid" modal expands to capture those fields + cash/card radio (currently just cash/card).
- New page `/admin/cashbook`:
  - Lists cash payments grouped by day + collecting agent.
  - Daily totals.
  - Handover action: agent records "handed to {manager} at {time}".
  - New collection `cashHandovers` (simple: `{ date, agentId, amount, handedTo, handedAt }`).

## Round F — Check-in list view + tabs

- View-mode toggle on `/admin/checkins` (Cards / List).
- List mode: flat table — date/time | plate | customer | type | status | payment | actions.
- Tabs across the top: Astăzi · Săptămâna asta · Toate · Pending plată.
